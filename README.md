# Pradyumn Mittal — Portfolio

Personal portfolio site. Plain HTML/CSS/JS, no build step, no dependencies.

## Structure

- `index.html` — all page content
- `styles.css` — design system (colors, type, layout) + light/dark theme
- `script.js` — theme toggle, stat-bar animation
- `assets/resume.pdf` — downloadable resume

## Preview locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

Hosted on GitHub Pages from the `main` branch root. Any push to `main` updates the live site.
